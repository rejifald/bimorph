---
title: 'Collect every bad field, not just the first'
description: 'Use the validate door on a composite to accumulate every failing path into a flat, form-library-shaped ErrorTree.'
---

A form submission has several bad fields and the user should see all of them at once,
not fix one and rediscover the next. Use the
[`validate`](/docs/guides/doors/validate) door on a composite: it accumulates every
failing path into a flat, form-library-shaped `ErrorTree` instead of throwing on the
first.

## Example

```ts twoslash
import { Struct, Field, Enum } from 'bimorph';

// [!code fold:start]
const Status = Enum([[1, 'active'], [0, 'inactive']], { recover: 'throw' });
const Kind = Enum([['a', 'alpha'], ['b', 'beta']], { recover: 'throw' });
// [!code fold:end]
const Row = Struct({
    status: Field('s', Status),
    kind: Field('k', Kind),
});

// both fields miss → every failing path at once, keyed by Field
const result = Row.validate({ s: 9, k: 'z' });
const errors = result.ok ? null : result.error;
//    ^?
```

On failure, `errors` is an `ErrorTree` — `{ status: …, kind: … }` here — a flat map
keyed by path (`"shipping.postalCode"` when nested). That shape drops straight onto a
form library that keys messages by field. On success, `validate` still returns the
decoded value, so it's "decode but collect", not a boolean check.
