---
title: 'Chain two codecs into one'
description: 'Compose a string↔date codec with a date↔domain codec using pipe, and watch the fidelity tier and context intersect automatically.'
---

You have two codecs that meet in the middle — a wire string that parses to cents, and
cents that convert to a domain dollar amount — and you want one codec end to end.
Chain them with [`pipe`](/docs/guides/composition/pipe): decode flows wire → mid →
domain, and the fidelity tier weakens to match the weaker link.

## Example

```ts twoslash
import { pipe, iso, lossy } from 'bimorph';

// [!code fold:start]
const StringToCents = iso<number, string>({
    decode: (s) => Number(s),
    encode: (n) => String(n),
});
const CentsToDollars = lossy<number, number>({
    decode: (cents) => cents / 100,
    encode: (dollars) => Math.round(dollars * 100),
});
// [!code fold:end]
// a is wire-facing (string ↔ cents), b is domain-facing (cents ↔ dollars)
const Price = pipe(StringToCents, CentsToDollars);

const dollars = Price.decode('1050');
//    ^?

// the composed codec is lossy — the weaker of iso and lossy
Price.fidelity;
//    ^?
```

`pipe` requires `a`'s domain to equal `b`'s wire — the middle type the value passes
through. It derives the rest for you: the fidelity is the weaker of the two, and if
either half were [contextual](/docs/concepts/context-requirement), the composed codec
would need both contexts merged.
