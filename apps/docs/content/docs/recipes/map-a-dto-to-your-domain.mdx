---
title: 'Map a wire DTO to your domain object'
description: 'Rename keys and convert each field with Struct and Field, so snake_case wire records become your camelCase domain type and back.'
---

A wire DTO uses `snake_case` keys and your domain type uses `camelCase`. Map the two
with [`Struct`](/docs/guides/composites/object) and
[`Field`](/docs/guides/composites/field): each `Field` names the wire key it reads and
the codec that converts it, so both directions come from one declaration.

## Example

```ts twoslash
import { Struct, Field, iso } from 'bimorph';

// [!code fold:start]
const num = iso<number, number>({ decode: (n) => n, encode: (n) => n });
const str = iso<string, string>({ decode: (s) => s, encode: (s) => s });
// [!code fold:end]
const User = Struct({
    id: Field('user_id', num),
    name: Field('full_name', str),
});

const user = User.decode({ user_id: 7, full_name: 'Ada' });
//    ^?

const dto = User.encode({ id: 7, name: 'Ada' });
//    ^?
```

`decode` produces your domain shape with renamed keys; `encode` reconstructs the wire
DTO. Swap the identity leaves here for real per-field codecs — an
[`Enum`](/docs/guides/enums/enum) for a status, a [date `iso`](/docs/guides/leaves/iso)
for a timestamp — and each field converts as it renames.
