When a mapping fails, the bare [doors](/docs/guides/doors/decode-and-encode) throw a
`BimorphError`. Its `detail` is a `DecodeError` carrying a stable `code` — and each
code has a page here, so a thrown error routes straight to its remediation.

## The code-to-docs contract

A `BimorphError.detail.code` is one of five stable strings, and the string is the
slug of its catalog page. Read the `code`, and you know where to look.

```ts twoslash
import { Enum, BimorphError } from 'bimorph';

const Status = Enum([[1, 'active'], [0, 'inactive']], { onMiss: 'throw' });

try {
    Status.decode(9);
} catch (e) {
    if (e instanceof BimorphError) {
        e.detail.code; // 'miss' → this page is /errors/miss
        e.detail.path; // where in the structure it failed
    }
}
```

The `code`s are an API: once published, a slug never changes.
