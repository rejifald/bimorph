---
title: 'Struct'
description: 'Map a struct field-by-field, with per-field rename and codec, and get the accumulate-all-errors validate door.'
---

Reach for `Struct` when a wire record maps to a domain object — each field renamed
and converted by its own codec. The result is itself a codec, so it decodes and
encodes the whole struct, and it carries the `validate` door for accumulating field
errors.

## Example

```ts twoslash
import { Struct, Field, iso } from 'bimorph';

// [!code fold:start]
const num = iso<number, number>({ decode: (n) => n, encode: (n) => n });
const str = iso<string, string>({ decode: (s) => s, encode: (s) => s });
// [!code fold:end]
// wire { user_id, full_name } ↔ domain { id, name } — keys renamed per Field
const User = Struct({
    id: Field('user_id', num),
    name: Field('full_name', str),
});

const domain = User.decode({ user_id: 7, full_name: 'Ada' });
//    ^?
```

## Options

`Struct` takes one record whose keys are your **domain** keys and whose values are
[`Field`](/docs/guides/composites/field) (or [`Group`](/docs/guides/composites/group))
entries. Each `Field(wireKey, codec)` names the wire key it reads and the codec that
converts it, so a wire key can differ from its domain key.

An `Struct` is more than the sum of its fields:

- It exposes the [`validate`](/docs/guides/doors/validate) door, which accumulates
  every failing field path into an `ErrorTree` instead of throwing on the first.
- Its encode output type **drops** fields marked
  [`encode: "omit"`](/docs/guides/composites/field), so a round-trip can't resend a
  read-only wire field.
- If any field is contextual, the `Struct` is contextual too: it **intersects** its
  fields' contexts into one bag and passes it down.

<Callout type="warn">
    **Anti-pattern:** don't use a `Field` per wire key when several wire keys
    collectively encode _one_ domain value — three booleans that mean one
    `visibility`. That's a [`Group`](/docs/guides/composites/group), which maps N
    wire keys to a single domain field; a pile of `Field`s would expose the wire
    shape your domain is trying to hide.
</Callout>
