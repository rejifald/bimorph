---
title: 'validate'
description: 'Accumulate every failing path into an ErrorTree on composites, instead of failing fast on the first bad field.'
---

Reach for `validate` on a composite when you want _every_ failing field at once — a
form submission where the user should see all the errors, not just the first. It's
decode-only and lives on `Struct`, `List`, and `Tuple`.

## Example

```ts twoslash
import { Struct, Field, Enum } from 'bimorph';

// [!code fold:start]
const Status = Enum([[1, 'active'], [0, 'inactive']], { onMiss: 'throw' });
const Kind = Enum([['a', 'alpha'], ['b', 'beta']], { onMiss: 'throw' });
// [!code fold:end]
const Row = Struct({
    status: Field('s', Status),
    kind: Field('k', Kind),
});

// both fields miss — validate collects BOTH paths instead of throwing on the first
const result = Row.validate({ s: 9, k: 'z' });
const errors = result.ok ? null : result.error;
//    ^?
```

## Options

`validate(b)` returns a `Result<A, ErrorTree>`: the decoded value on success, or an
`ErrorTree` collecting every failure on the way down. An `ErrorTree` is a **flat,
path-keyed map** — `{ "shipping.postalCode": … }`, not a nested object — which drops
straight onto form libraries that key errors by field path.

This is the accumulating counterpart to
[`safeDecode`](/docs/guides/doors/safe-doors), which fails fast on the first bad
path. `validate` still returns the decoded value on success, so it's "decode but
collect", not a boolean checker.

<Callout type="warn">
    **Anti-pattern:** don't look for `validate` on a leaf codec like `iso` or
    `Enum` — a leaf has one thing to fail and nothing to accumulate, so the door
    isn't on its type. Use [`safeDecode`](/docs/guides/doors/safe-doors) there; save
    `validate` for composites.
</Callout>
