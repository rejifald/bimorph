bimorph is a library for **bidirectional data mapping**: you define a mapping once
and get both directions from it — `decode` reads an external value into your domain,
`encode` writes it back out. It exists because most real mappings don't invert
cleanly, and pretending they do is how a wrong reverse ships.

## The pain it removes

A lookup object gives you one direction cleanly and leaves you to hand-write the
other — where it drifts the moment someone edits one half:

```ts twoslash
const STATUSES = { 0: 'inactive', 1: 'active' } as const;

const label = STATUSES[1]; // easy — the forward direction

// the reverse: hand-written, untyped, and loose
const code = Object.entries(STATUSES).find(([, v]) => v === 'active')?.[0];
//    ^?
```

A codec keeps the pair together, so one declaration is both directions and the
result is narrowed, not `string | undefined`:

```ts twoslash
import { Enum } from 'bimorph';

const Status = Enum([
    [0, 'inactive'],
    [1, 'active'],
]);

const label = Status.decode(1);
const code = Status.encode('active');
//    ^?
```
