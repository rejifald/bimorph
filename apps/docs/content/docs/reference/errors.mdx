The error and result types every door speaks. A failing door either throws a
`BimorphError` or hands you a `Result` whose `error` branch carries a `DecodeError`.

## DecodeError

The shape of every failure — thrown by the bare doors, and carried in the `error`
branch of a `Result`.

<AutoTypeTable path="../../src/index.ts" name="DecodeError" />

## Result

`safeDecode` and `safeEncode` return a `Result` — a plain discriminated union,
`{ ok: true; value } | { ok: false; error }` — never a wrapper class.

```ts twoslash
import { Enum } from 'bimorph';

const Status = Enum([[1, 'active'], [0, 'inactive']], { recover: 'throw' });
const r = Status.safeDecode(9);
//    ^?
```

## ErrorTree

The accumulate door, [`validate`](/docs/guides/doors/validate), returns a
`Result<A, ErrorTree>`. An `ErrorTree` is a flat, path-keyed map of failures —
`{ "shipping.postalCode": DecodeError }` — not a nested object.

```ts twoslash
import type { ErrorTree } from 'bimorph';
```

## BimorphError

The `Error` subclass the bare doors throw. Its `detail` is the `DecodeError` above.

```ts twoslash
import { BimorphError } from 'bimorph';

const e = new BimorphError({ path: '', code: 'miss', input: 9, message: 'no mapping' });
const detail = e.detail;
//    ^?
```
