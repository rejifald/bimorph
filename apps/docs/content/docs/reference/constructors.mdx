Every function that builds a codec (or a field of one), and the fidelity tier it
produces. Each links to its guide for the full signature and a worked example.

## The surface

```ts twoslash
import {
    iso,
    lossy,
    partial,
    Enum,
    Struct,
    Field,
    Group,
    List,
    Tuple,
    Nullable,
    pipe,
} from 'bimorph';
```

## Constructors

| Function              | Builds                                   | Fidelity                | Guide                                             |
| --------------------- | ---------------------------------------- | ----------------------- | ------------------------------------------------- |
| `iso(spec)`           | a leaf codec, exact round-trip           | `iso`                   | [iso](/docs/guides/leaves/iso)                    |
| `lossy(spec)`         | a leaf codec, no round-trip promise      | `lossy`                 | [lossy](/docs/guides/leaves/lossy)                |
| `partial(spec)`       | a leaf codec, fallible decode            | `partial`               | [partial](/docs/guides/leaves/partial)            |
| `Enum(entries, opts)`| a discrete key↔value map                 | `iso`                   | [Enum](/docs/guides/enums/enum)                  |
| `Struct(fields)`      | a struct codec + the `validate` door     | weakest of its fields   | [object](/docs/guides/composites/object)          |
| `Field(key, codec)`   | one field of an `Struct` (rename + omit) | (of its codec)          | [field](/docs/guides/composites/field)            |
| `Group(keys, codec)`  | one field mapping N wire keys ↔ 1 value  | (of its codec)          | [group](/docs/guides/composites/group)            |
| `List(codec)`        | a homogeneous list codec                 | (of its element)        | [array & tuple](/docs/guides/composites/array-and-tuple) |
| `Tuple(...codecs)`    | a fixed-length heterogeneous list codec  | weakest of its elements | [array & tuple](/docs/guides/composites/array-and-tuple) |
| `Nullable(codec)`     | a null/absent ↔ undefined wrapper        | (of its codec)          | [optional](/docs/guides/composites/optional)      |
| `pipe(a, b)`          | two codecs composed end to end           | weakest of the two      | [pipe](/docs/guides/composition/pipe)             |

## Shapes

The three families share a shape:

- **Leaf constructors** — `iso`, `lossy`, `partial` — take one `{ decode, encode }`
  spec. `partial`'s `decode` returns a `Result`; the other two return the value.
- **Composite constructors** — `Struct`, `List`, `Tuple` — take codecs (or
  `Field`/`Group` entries) and expose the [`validate`](/docs/guides/doors/validate)
  door. `Field` and `Group` build entries _for_ an `Struct`, not standalone codecs.
- **`pipe`** composes two codecs, requiring `a`'s domain to equal `b`'s wire.

`Enum` is its own shape: an entries array plus optional
[`aliases`](/docs/guides/enums/aliases), [`onMiss`](/docs/guides/enums/on-miss), and
[`onCollision`](/docs/guides/enums/on-collision).
