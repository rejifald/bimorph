# `pipe` — composing codecs

`pipe(a, b)` chains two codecs through a shared middle representation: `a` maps wire
`B` ↔ mid `M`, `b` maps mid `M` ↔ domain `A`. Decode flows `B → M → A`, encode flows
`A → M → B`. Two properties compose automatically — **fidelity weakens** to the worse
of the two, and **context intersects**.

## Fidelity weakens: `iso ∘ lossy = lossy`

```ts twoslash
import { iso, lossy, pipe } from 'bimorph'

// wire (raw) ↔ mid (trimmed): trimming is lossy — the stripped spaces can't be restored
const Trimmed = lossy<string, string>({
  decode: (raw) => raw.trim(),
  encode: (clean) => clean,
})
// mid (trimmed) ↔ domain (number)
const NumFromStr = iso<number, string>({
  decode: (s) => Number(s),
  encode: (n) => String(n),
})

const NumField = pipe(Trimmed, NumFromStr)
//    ^?

NumField.decode('  42  ') // 42
NumField.encode(42) // "42"
```

## A `partial` anywhere in the chain makes the whole chain `partial`

The composed codec loses its throwing `decode` door — you're forced through
`safeDecode`, exactly as if the partial step were used alone.

```ts twoslash
// @errors: 2551
import { lossy, partial, pipe } from 'bimorph'

const Trimmed = lossy<string, string>({ decode: (r) => r.trim(), encode: (c) => c })

const Name = partial<{ first: string; last: string }, string>({
  decode: (full) => {
    const [first, ...rest] = full.split(' ')
    return rest.length
      ? { ok: true, value: { first: first!, last: rest.join(' ') } }
      : { ok: false, error: { path: '', code: 'ambiguous', input: full, message: 'mononym' } }
  },
  encode: (n) => `${n.first} ${n.last}`,
})

const TrimmedName = pipe(Trimmed, Name)

TrimmedName.safeDecode('  Mary Jane Watson ') // ok — safe door survives
TrimmedName.decode('Madonna') // ✗ result is Partial: no throwing decode
```

## Context intersects across the chain

Each step needs a different context; the composed codec requires **both**, and `bind`
still collapses it back to an ordinary codec.

```ts twoslash
import { iso, pipe } from 'bimorph'

const Regionalize = iso<string, string, { region: string }>({
  decode: (raw, { region }) => `${region}:${raw}`,
  encode: (mid) => mid.split(':')[1]!,
})
const Localize = iso<string, string, { locale: string }>({
  decode: (mid, { locale }) => `${locale}/${mid}`,
  encode: (dom) => dom.split('/')[1]!,
})

const Chain = pipe(Regionalize, Localize)
//    ^?

Chain.decode('x', { region: 'US', locale: 'en-US' })

const bound = Chain.bind({ region: 'US', locale: 'en-US' })
const out = bound.decode('x')
//    ^?
```

Supplying neither context is a compile error:

```ts twoslash
// @errors: 2554
import { iso, pipe } from 'bimorph'

const Regionalize = iso<string, string, { region: string }>({ decode: (r, { region }) => r, encode: (m) => m })
const Localize = iso<string, string, { locale: string }>({ decode: (m, { locale }) => m, encode: (d) => d })

const Chain = pipe(Regionalize, Localize)

Chain.decode('x')
```

## Asymmetric wire types survive composition

An aliased `enum_` has a **wide** decode input (canonical + legacy) and a **narrow**
encode output (canonical only). `pipe` propagates that split instead of collapsing it,
so the alias guarantee — "encode never emits a legacy spelling" — holds *through*
composition. Decode still accepts the legacy spelling; encode is still typed narrow.

```ts twoslash
import { enum_, iso, pipe } from 'bimorph'

const Status = enum_([['ACTIVE', 'active'], ['INACTIVE', 'inactive']], {
  aliases: [['A', 'active']], // legacy spelling, decode-only
})
// mid (Status' domain) ↔ a display label
const Display = iso<'Active' | 'Inactive', 'active' | 'inactive'>({
  decode: (s) => (s === 'active' ? 'Active' : 'Inactive'),
  encode: (d) => (d === 'Active' ? 'active' : 'inactive'),
})

const Labelled = pipe(Status, Display)

Labelled.decode('A') // legacy spelling still accepted on decode

// encode output stays the narrow, canonical-only union — no leaked 'A':
const wire = Labelled.encode('Active')
//    ^?
```

The wide input is still a closed union, so an unknown wire value is a compile error
even after composition:

```ts twoslash
// @errors: 2345
import { enum_, iso, pipe } from 'bimorph'

const Status = enum_([['ACTIVE', 'active']], { aliases: [['A', 'active']] })
const Display = iso<'X', 'active'>({ decode: () => 'X', encode: () => 'active' })

const Labelled = pipe(Status, Display)

Labelled.decode('totally-unknown')
```
